# 阶段 4 执行结果（编码阶段第一批）

## 已完成

1. **工程与依赖初始化**
   - 升级为 Kotlin + Compose 工程骨架。
   - 引入 Material 3、Navigation Compose、Coroutines。
   - 引入 OkHttp3 + Retrofit + Moshi。
   - 引入 DataStore（token 持久化）。

2. **网络基础设施**
   - 新增 `PicacgApiService`，落地 `auth/sign-in` 接口。
   - 新增 `ApiResult` 统一结果模型。
   - 新增拦截器链：
     - `HeaderInterceptor`（公共头）
     - `SignatureInterceptor`（签名）
     - `AuthInterceptor`（授权头）
   - 新增 `PicacgNetworkModule` 统一创建 Retrofit/OkHttp。

3. **认证流程（MVP）**
   - 新增 `AuthTokenStore`：DataStore 持久化 token。
   - 新增 `AuthRepository.login()`：请求登录并保存 token。
   - 新增 `SessionViewModel`：管理登录状态。
   - 新增 Compose 登录界面：邮箱/密码输入与登录按钮。

## 当前状态

- 已能完成“登录流程骨架 + token 持久化 + 登录态 UI 切换”。
- 尚未完成自动续期、401 全局处理、首页/分类/搜索/详情等业务模块。

## 下一步

- 进入阶段 4 的下一批任务：
  1. 首页/分类/搜索接口与页面实现。
  2. 漫画详情与章节列表。
  3. 阅读器 MVP（图片分页加载 + 进度保存）。
